## About this entry

The line is a crypto trading joke told in three beats. First the
trader buys the dip, the bravest move in the book, then the dip buys
a shovel and digs deeper, which is how every dip actually behaves,
and finally the group chat stops sending tips and starts sending
condolences. That last turn is the laugh, because anyone who has
held a bag knows the exact moment the chat goes quiet and then
sympathetic. The details are earned rather than generic, the dip,
the shovel, and the group chat are all things a real trader
recognises at once, and the whole joke fits in a single line well
inside the two hundred character cap. The program holds the line,
checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
